Personal project · 2025 — present

Plan Execute

Helping people examine the work an agent hands back.

An agent can finish a task while leaving its user with questions: Where did this come from? What should I check? What happens if I disagree?

I’m building a workspace that connects the result to its sources and gives those questions a place to go. A user can inspect the supporting material, ask about a specific part, and return to the original work.

What I’ve built
  • A bridge between agent work and a separate reading and follow-up workspace, carrying the source version, question, and return location.
  • Persistent conversations, drafts, and reading positions using SQLite, with FastAPI and Next.js.
  • Source-linked explanations and contextual follow-up questions that keep the original material close at hand.
