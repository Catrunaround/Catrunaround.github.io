    Jul – Aug 2026

    Robot deployment and safety

    hitchopen/HOPE · ★ 46

    HOPE Humanoid table tennis on the Agibot A3

    An open challenge platform for humanoid table tennis from Hitch Interactive and Berkeley's ROAR platform. My public work there is on the deployment side: running policies on the real robot safely.

    • Packaged a fixed-motion serve for the A3's arms. The vendor stack keeps the waist, legs, and neck while my runner takes over only the 14 arm joints, with a SHA-256-bound package, a read-only preflight, and a guarded handoff and restore. #18
    • Added guarded run controls for the deployed policy, covering prepare, policy, PD stand, passive, and E-stop. The robot enters the policy only from a settled stand with a fresh calibration. #26
    • Added per-run calibration from NatNet motion-capture markers to the robot's CAD frame, with an atomic approval step and fail-closed checks in the base-pose relay. #26
    • Updated the Foxglove controls, ROS 2 bringup, and unit tests for the runner, calibration, and safety contracts. #26

    Apr – May 2026

    Data systems course project

    yikangyu-usc/dsci-551-movielens-project

    MovieLens Analytical API DuckDB over 32 million ratings

    A DSCI 551 project: a FastAPI service that runs analytical queries over the MovieLens 32M dataset on DuckDB.

    • Built the API and the DuckDB layer for the four application operations the course required, with a demo script that reproduces the results.
    • Mapped each operation to DuckDB internals, columnar storage and vectorized execution, and checked the query plans with EXPLAIN ANALYZE.
    • Compared the design with MySQL and MongoDB, and documented setup, data loading, and reproduction end to end.
