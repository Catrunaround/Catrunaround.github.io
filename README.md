# Yikang (Ethan) Yu — personal website

Static personal website served by GitHub Pages from `main` at https://catrunaround.github.io/.

## Preview

Run `python3 -m http.server 8765 --bind 127.0.0.1` in this directory and open http://127.0.0.1:8765/.

## Maintenance

- Edit `index.html` for content and `styles.css` for presentation. No build step or JavaScript is required.
- `assets/Yikang_Ethan_Yu_Resume.pdf` is the supplied full general résumé, copied without modification. Replace it with the next reviewed version and update the displayed page count if needed.
- Keep institutional roles and dates distinct from individual project contribution dates. Label research status and distinguish personal contributions from team work.
- Preserve direct evidence links. Do not present code volume, team demonstrations, simulation benchmarks, or infrastructure tests as individual impact or real-world effectiveness.
- Check desktop and phone layouts, anchor links, the expandable project details, and PDF viewing/download after changes.
